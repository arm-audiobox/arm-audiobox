# esp32 display firmware

ESP32 firmware for external displays used with supported audio player projects.

## Scope

- Firmware source and build instructions.
- Flashing instructions and board configuration.
- Display wiring and USB or serial connection documentation.
- Track information, cover artwork and clock views where supported.
- Host-side requirements and compatibility notes for each player platform.

## Status

This directory is prepared for firmware and documentation. No firmware sources or binaries have been imported here yet.

Supported ESP32 boards, display controllers, pin assignments and player integrations will be documented for each firmware configuration. Display support depends on both the firmware and the connected player.
