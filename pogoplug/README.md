# pogoplug

Buildroot-based network audio player projects for the **PogoPlug E02**.

## Scope

- Platform configuration and build instructions for the E02.
- USB audio output and web interface integration.
- Playback service configuration and maintenance documentation.

## Status

This directory is prepared for project files and documentation. No firmware images or build sources have been imported here yet.

OXNAS-based devices are covered separately in [oxnas](../oxnas/README.md). Firmware images and hardware instructions must match the exact device model.
