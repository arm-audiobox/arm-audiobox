# audioplayer

**audioBox and other DIY audio player projects**, including Raspberry Pi players and related hardware.

## Scope

- Player firmware and build instructions.
- Web interfaces and playback service integration.
- Display and control interfaces for supported hardware.
- Hardware notes, configuration examples and enclosure documentation.

## Status

This directory is prepared for project files and documentation. No firmware images or build sources have been imported here yet.

Supported boards, displays and playback services will be listed for each project. Features from one hardware platform do not automatically apply to another.

For PogoPlug projects, see [pogoplug](../pogoplug/README.md) and [oxnas](../oxnas/README.md).
